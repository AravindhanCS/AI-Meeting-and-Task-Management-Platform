# Project Requirements

## Project Name

**AI Meeting & Task Management Platform**

---

## Problem Statement

In many organizations, meetings involve important discussions, decisions, and task assignments. However, attendees often forget the details discussed during the meeting or misunderstand the responsibilities assigned to them. Manual note-taking and task tracking are time-consuming and can lead to missed deadlines, poor communication, and reduced team productivity.

The goal of this application is to provide a centralized platform for managing meetings, tracking tasks, and improving collaboration among team members. In later versions, Artificial Intelligence (AI) will be integrated to automatically summarize meeting discussions, identify action items, and assist users in planning and managing their work more efficiently.

---

## Target Users

* **Admin** – Manages the application, users, roles, and permissions.
* **Higher Management** – Views project progress, meeting summaries, and overall team performance.
* **Team Lead** – Creates workspaces and projects, schedules meetings, assigns tasks, and monitors progress.
* **Team Member** – Participates in meetings, views assigned tasks, updates task status, and collaborates with the team.
* **Guest/External User (Optional)** – Can be granted limited access to specific workspaces or projects when required.

---

## Core Features (Minimum Viable Product)

### User Management

* User Registration
* User Login
* User Logout
* Role-Based Authentication and Authorization

### Workspace Management

* Create Workspace
* View Workspace
* Update Workspace
* Delete Workspace

### Project Management

* Create Project
* View Project
* Update Project
* Delete Project

### Meeting Management

* Schedule or Create Meetings
* Store Meeting Details
* Upload Meeting Notes or Meeting Transcript
* View Previous Meetings

### Task Management

* Create Tasks
* Assign Tasks to Team Members
* Update Task Status
* Edit Task Details
* Delete Tasks
* View Assigned Tasks

### Access Control

* Role-Based Permissions
* Workspace and Project Level Access Control

### Dashboard

* View Pending Tasks
* View Completed Tasks
* View Overdue Tasks
* View Project Progress

## Project Objective

The primary objective of this project is to learn and apply modern ASP.NET Core backend development concepts while building a production-style application. The project will demonstrate skills in REST API development, authentication and authorization, database design, Entity Framework Core, clean architecture, logging, validation, testing, and AI integration. It will serve as a portfolio project that showcases practical software engineering skills expected in product-based companies.
