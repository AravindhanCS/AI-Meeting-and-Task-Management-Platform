# Core Entities

1. User
Purpose:
Represents every person who can log in to the application.

2. Workspace
Purpose:
Represents a team or department where projects are managed.

3.Workspace Member
Purpose:
This entity stores who belongs to which workspace and, if needed later, what role they have in that workspace.

4. Project
Purpose:
Represents a project inside a workspace.

5. Task
Purpose:
Represents an action item assigned to one or more users as a result of project work or meetings.

6. Meeting
Purpose: 
Represents every meeting that is being conducted or will be conducted

7. Role
Purpose:
Represents role of every user

8. Meeting Summary (future enhancement)
Purpose:
Represents the summary details
